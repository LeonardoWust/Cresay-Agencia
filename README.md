# Cresay Agência

Landing page da Cresay, uma agência de marketing digital, voltada a empresas e profissionais que buscam serviços de marketing. Apresenta a agência, seus serviços e trabalhos para ajudar potenciais clientes a conhecê-la e entrar em contato.

## Tecnologias

- React 18 e TypeScript
- Vite
- Tailwind CSS 4

## Como rodar

```bash
pnpm install
pnpm run dev
```

Para gerar a versão de produção:

```bash
pnpm run build
```
